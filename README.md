# Block Fast learning

A Moodle block that allows you to link cross-curricular learning resources for users to access. These resources can be linked to a specific course or assigned globally.

Package tested in: 5.1+.

## QUICK INSTALL
Download zip package, extract the fastlearning folder and upload this folder into blocks/.
